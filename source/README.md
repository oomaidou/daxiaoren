# 打小人 · 暮色山林

一个单文件 HTML 的俯视角无尽生存射击小游戏。无需联网、无需安装。游戏内置中文 / English，会自动识别浏览器语言，也可以在开始界面点 `EN / 中文` 或按 `L` 切换。

## 打开方式

- 直接双击项目根目录的 `index.html`（推荐，一个文件就能玩）。
- 或打开本目录的 `index.html`（源码版，样式和脚本分开，方便继续改）。

修改源码后，回到项目根目录运行 `python3 build.py`，会重新生成单文件版 `index.html`。

## 操作

| 操作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 左半屏拖动 |
| 瞄准 | 鼠标 | 右半屏拖动 |
| 攻击 | 鼠标左键（按住连发） | 右半屏按住 |
| 换武器 | `1` `2` `3` `4` / 滚轮 / `Q` | 右下「换」 |
| 装弹 | `R` | 右下「弹」 |
| 冲刺 | `Shift` | 摇杆推到底自动冲刺 |
| 翻滚 | `空格` | — |
| 地洞 | `E` | 右下「洞」（靠近地洞时出现） |
| 暂停 | `Esc` / `P` | 左上暂停键 |
| 静音 | `M` | — |
| 切换语言 | `L` | 开始界面 `EN / 中文` |

## 武器数值

| 武器 | 伤害 | 说明 |
| --- | --- | --- |
| 拳头 | 18 | 无消耗，击退强 |
| 猎刀 | 48 + 8/秒流血 | 近战扇形，适合贴脸 |
| 步枪 | 26 / 发，30 发弹匣 | 备弹无限，`R` 装弹 |
| 手榴弹 | 260（范围内衰减） | 最多带 5 枚，会炸到自己 |

玩家生命 1000，每秒回复 10。小人没有血条，死亡后持续补充，人数会随时间变多。

## 地图机制

- 山腰的**庇护所**：木墙能挡子弹，只有一个南门，里面不会被远程打到（也没有远程敌人）。
- **地洞**：走到洞口按 `E` 钻进去，小人无法攻击你，会转而互相残杀；再按 `E` 爬出。
- **红色油桶**：打爆会引发范围爆炸，可以连锁，也能炸伤你自己。
- **内讧**：小人被挡住或找不到你时会互相攻击，刀和手榴弹都能误伤同伴。

## 开发说明

源码在 `打小人/`：

- `index.html` — 页面结构
- `style.css` — HUD、菜单、触屏布局
- `game.js` — 全部玩法逻辑（原生 Canvas，无第三方依赖）

调试参数：

- `index.html?dev=1`：跳过开始界面直接开局
- `index.html?dev=1&enemies=1`：开局并刷一圈敌人
